# Awesome Free Illustrations & Animations for Websites

A curated collection of websites where designers and developers can find free illustrations, animations, icons, and visual assets for websites, landing pages, templates, and UI design.

Always check the individual license before using an asset in a commercial project.

## Tips for Using Free Assets

* Check the license before downloading.
* Check whether commercial use is allowed.
* Keep attribution requirements in mind.
* Download assets from the original source whenever possible.
* Don't redistribute assets as standalone files if the license prohibits it.
* Optimize SVGs and animations before using them on production websites.
* Test animations on mobile devices.
* Avoid using too many animations on a single page.
